🧩 Regex Basics — Character Classes & Quantifiers

The building blocks of every pattern you'll write.

📝 1.1 Literal Characters & Wildcard

Most characters match themselves. The dot . matches any single character.

Step-by-step explanation:

  • Step 1: Import re.
  • Step 2: Use re.findall() to see all matches.
  • Step 3: Notice . matches any single character.
python 
import re

text = "cat bat hat mat"

# Literal pattern
print("'cat':", re.findall("cat", text))

# Dot wildcard
print("'.at':", re.findall(".at", text))

# Dot matches any char
print("'c.t':", re.findall("c.t", text))
💡 . does not match a newline by default. Use the DOTALL flag to change that.

📝 1.2 Character Classes [...]

Match any one of several characters using square brackets.

Step-by-step explanation:

  • Step 1: Use [abc] to match any of a, b, c.
  • Step 2: Use [a-z] for a range.
  • Step 3: Use [^...] to negate the class.
python 
import re

text = "The year 2026 has 12 months and 365 days."

# Digits only
print("digits:", re.findall(r"\d+", text))

# Multiple digits
print("[0-9]+:", re.findall(r"[0-9]+", text))

# Letters only
print("[a-z]+:", re.findall(r"[a-z]+", text))

# Alternation of vowels
print("[aeiou]:", re.findall(r"[aeiou]", "hello world", re.I))

# Negated class — anything not a digit
print("[^0-9]+:", re.findall(r"[^0-9]+", "a1b2c3"))

📝 1.3 Common Character Shorthand

Memorize these shorthand classes — you'll use them constantly.

PatternMatchesExample
\dDigit[0-9]
\DNon-digit[^0-9]
\wWord char[a-zA-Z0-9_]
\WNon-word[^a-zA-Z0-9_]
\sWhitespacespace, \t, \n
\SNon-whitespaceanything else
.Any char (except newline)
python 
import re

text = "Order #A12345 shipped on 2026-06-30"

print("\\d+:", re.findall(r"\d+", text))
print("\\w+:", re.findall(r"\w+", text))
print("\\S+:", re.findall(r"\S+", text))
print("\\s+:", re.findall(r"\s+", text))
✨ Always use raw strings r"..." for regex patterns — otherwise Python interprets \d as an escape sequence.

📝 1.4 Quantifiers * + ? {n,m}

Control how many times a character or group repeats.

QuantifierMeaningExample
*0 or morea*
+1 or morea+
?0 or 1a?
{n}Exactly na{3}
{n,}n or morea{3,}
{n,m}Between n and ma{2,4}
python 
import re

print("a*:  ", re.findall(r"ab*c", "ac abc abbc abbbc"))
print("a+:  ", re.findall(r"ab+c", "ac abc abbc abbbc"))
print("a?:  ", re.findall(r"ab?c", "ac abc abbc"))
print("{2,3}:", re.findall(r"ab{2,3}c", "abc abbc abbbc abbbbc"))
print("{3}: ", re.findall(r"\d{3}", "1 12 123 1234 12345"))
💡 Quantifiers are greedy by default — they match as much as possible. Add ? after to make them lazy: *?, +?, ??, {n,m}?.

📝 1.5 Anchors ^ $ \b

Match positions rather than characters.

Step-by-step explanation:

  • Step 1: ^ matches the start of the string (or line with MULTILINE).
  • Step 2: $ matches the end of the string.
  • Step 3: \b matches a word boundary.
python 
import re

text = "hello world hello"

print("^hello:", re.findall(r"^hello", text))
print("hello$:", re.findall(r"hello$", text))
print("\\bworld\\b:", re.findall(r"\bworld\b", text))
print("\\bhello\\b:", re.findall(r"\bhello\b", text))

# MULTILINE demo
multiline = "start\nmiddle\nend"
print("\nstarts:", re.findall(r"^\w+", multiline, re.M))
print("ends:  ", re.findall(r"\w+$", multiline, re.M))
⚠️ ^ and $ are by default anchored to start/end of the entire string. Use re.M for per-line anchors.

🎯 match vs search

The two main matching functions — and when to use each.

📝 2.1 re.match() — Anchor at Start

match() only matches at the beginning of the string.

Step-by-step explanation:

  • Step 1: Call re.match(pattern, text).
  • Step 2: Returns a Match object or None.
  • Step 3: Check with if m:.
python 
import re

text = "hello world"

m = re.match(r"hello", text)
print("Match hello:", m)
print("Group:      ", m.group() if m else None)

m2 = re.match(r"world", text)
print("\nMatch world:", m2)

# Match vs search
print("\nsearch world:", re.search(r"world", text))
💡 re.match(p, s) is equivalent to re.search(r"^" + p, s) — but faster.

📝 2.2 re.search() — Find Anywhere

search() scans the string and returns the first match anywhere.

Step-by-step explanation:

  • Step 1: Call re.search(pattern, text).
  • Step 2: Returns the first match or None.
  • Step 3: Use .start() and .end() for positions.
python 
import re

text = "The year is 2026 and we are in June"

m = re.search(r"\d+", text)
if m:
    print("Found:", m.group())
    print("Start:", m.start())
    print("End:  ", m.end())

# Search for missing pattern
m2 = re.search(r"\d{5}", text)
print("\n5 digits:", m2)

# Multiple candidates — search returns the FIRST
m3 = re.search(r"\w+", "first second third")
print("\nFirst word:", m3.group())

📝 2.3 fullmatch() — Match the Entire String

fullmatch() requires the pattern to match the entire string.

Step-by-step explanation:

  • Step 1: Use fullmatch() for validation.
  • Step 2: Returns a match only if the pattern covers the whole string.
  • Step 3: Ideal for validating formats like phone numbers.
python 
import re

# Validate a 3-letter code
print(re.fullmatch(r"[A-Z]{3}", "ABC"))
print(re.fullmatch(r"[A-Z]{3}", "ABCD"))  # None — too long

# Validate a phone number
phone = "555-1234"
m = re.fullmatch(r"\d{3}-\d{4}", phone)
print("\nPhone valid:", bool(m))

# Wrong format
bad = "555-12345"
print("Bad valid:  ", bool(re.fullmatch(r"\d{3}-\d{4}", bad)))
✨ Use fullmatch() for form validation — it's the cleanest way to enforce a complete format.

📋 findall & finditer — Get All Matches

Extract every match, not just the first.

📝 3.1 re.findall()

Returns a list of all matches as strings (or tuples if the pattern has groups).

Step-by-step explanation:

  • Step 1: Call re.findall(pattern, text).
  • Step 2: Returns a list of strings.
  • Step 3: With groups, returns a list of tuples.
python 
import re

text = "Emails: alice@example.com, bob@test.org, carol@site.net"

emails = re.findall(r"\S+@\S+", text)
print("Emails:", emails)
print("Count:  ", len(emails))

# Numbers
nums = re.findall(r"\d+", "Order 123, item 456, qty 789")
print("\nNumbers:", nums)

# With groups — returns tuples
pairs = re.findall(r"(\w+)@(\w+)", text)
print("\nPairs:", pairs)
💡 If the pattern has one capture group, findall() returns a list of strings; with multiple groups, a list of tuples.

📝 3.2 re.finditer()

Returns an iterator of Match objects — better for large inputs or when you need positions.

Step-by-step explanation:

  • Step 1: Use re.finditer(pattern, text).
  • Step 2: Iterate over the Match objects.
  • Step 3: Access .group(), .start(), .end().
python 
import re

text = "IDs: A101, B202, C303"

for m in re.finditer(r"[A-Z](\d+)", text):
    print(f"Match: {m.group()}, digits: {m.group(1)}, position: {m.start()}")
✨ finditer() is lazy — it yields matches one at a time, saving memory for large files.

🔄 Substitution — re.sub() & re.split()

Replace matched patterns or split strings using regex.

📝 4.1 re.sub() — Replace Matches

Replace every match with a string or function result.

Step-by-step explanation:

  • Step 1: Call re.sub(pattern, replacement, text).
  • Step 2: Use \1, \2 to reference captured groups.
  • Step 3: Limit replacements with count=n.
python 
import re

text = "The price is $100 and the discount is $20"

# Simple replacement
masked = re.sub(r"\d+", "N", text)
print("Masked:", masked)

# With groups — reorder date
date = "2026-06-30"
us = re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\2/\3/\1", date)
print("\nUS date:", us)

# Limit replacements
limited = re.sub(r"\d+", "X", text, count=1)
print("\nLimited:", limited)

# Replace with function
def double(match):
    return str(int(match.group()) * 2)

print("\nDoubled:", re.sub(r"\d+", double, text))
💡 For complex replacements, passing a function is often cleaner than juggling backreferences in the replacement string.

📝 4.2 re.split() — Split on Pattern

Split a string wherever the pattern matches.

Step-by-step explanation:

  • Step 1: Call re.split(pattern, text).
  • Step 2: Split on multiple delimiters at once.
  • Step 3: Optionally limit splits with maxsplit.
python 
import re

# Split on multiple delimiters
text = "apple,banana;cherry orange"
parts = re.split(r"[,;\s]+", text)
print("Parts:", parts)

# Split on digits
print("\nSplit on digits:", re.split(r"\d+", "a1b22c333d"))

# Limit splits
print("\nMaxsplit=2:", re.split(r"\s+", "a b c d e", maxsplit=2))
✨ re.split() is much more flexible than str.split() — it handles multiple delimiters at once.

📦 Groups — Capture & Reuse Subpatterns

Extract substrings and organize complex patterns.

📝 5.1 Numbered Groups (...)

Parentheses capture substrings you can reference later.

Step-by-step explanation:

  • Step 1: Wrap parts of the pattern in (...).
  • Step 2: Access with .group(1), .group(2).
  • Step 3: Use .groups() for a tuple of all groups.
python 
import re

text = "John Smith, 30 years old"
m = re.search(r"(\w+)\s+(\w+),\s+(\d+)", text)

if m:
    print("Whole match:", m.group(0))
    print("First name: ", m.group(1))
    print("Last name:  ", m.group(2))
    print("Age:        ", m.group(3))
    print("All groups: ", m.groups())
💡 .group(0) is the entire match. .group(1) is the first parenthesized group.

📝 5.2 Named Groups (?P<name>...)

Give groups names for clarity and easier access.

Step-by-step explanation:

  • Step 1: Use (?P<name>pattern) syntax.
  • Step 2: Access with .group("name") or .groupdict().
python 
import re

text = "2026-06-30"
m = re.search(r"(?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})", text)

if m:
    print("Year:  ", m.group("year"))
    print("Month: ", m.group("month"))
    print("Day:   ", m.group("day"))
    print("Dict:  ", m.groupdict())
✨ Named groups are self-documenting — use them for readability, especially in complex patterns.

📝 5.3 Non-Capturing Groups (?:...)

Group without capturing — useful for applying quantifiers without affecting group numbering.

Step-by-step explanation:

  • Step 1: Use (?:...) instead of (...).
  • Step 2: Apply quantifiers to the whole group.
  • Step 3: Groups don't appear in .groups().
python 
import re

# Match repeated words without capturing each "ha"
text = "hahaha hehehe hihihi"
print("Captured:    ", re.findall(r"(ha)+", text))
print("Non-captured:", re.findall(r"(?:ha)+", text))

# Alternation inside a group
pattern = r"(?:cat|dog)s?"
print("\nAnimals:", re.findall(pattern, "cat cats dog dogs"))

🚀 Advanced — Lookaheads, Lookbehinds & Backreferences

Power-user patterns for sophisticated matching.

📝 6.1 Lookaheads (?=...) and (?!...)

Assert that a pattern follows without consuming characters.

Step-by-step explanation:

  • Step 1: (?=...) is a positive lookahead.
  • Step 2: (?!...) is a negative lookahead.
  • Step 3: The lookahead characters aren't included in the match.
python 
import re

text = "apple pie, apple cake, apple juice"

# Match "apple" only if followed by " pie"
print("Before pie:", re.findall(r"apple(?= pie)", text))

# Match "apple" NOT followed by " pie"
print("Not pie:   ", re.findall(r"apple(?! pie)", text))

# Password validator: 8+ chars, at least one digit
password = "abc12345"
if re.search(r"^(?=.*\d).{8,}$", password):
    print("\nPassword valid")
else:
    print("\nPassword invalid")
💡 Lookaheads don't consume characters — perfect for validation that requires multiple conditions.

📝 6.2 Lookbehinds (?<=...) and (?<!...)

Assert that a pattern precedes the match.

Step-by-step explanation:

  • Step 1: (?<=...) requires the pattern to appear before.
  • Step 2: (?<!...) requires it NOT to appear before.
  • Step 3: Lookbehinds must be fixed-length.
python 
import re

text = "USD100 EUR200 USD300"

# Match amounts ONLY after USD
print("USD amounts:", re.findall(r"(?<=USD)\d+", text))

# Match amounts NOT after USD
print("Non-USD:    ", re.findall(r"(?<!USD)\d+", text))

# Extract the currency code before numbers
print("\nCurrency codes:", re.findall(r"[A-Z]{3}(?=\d)", text))

📝 6.3 Backreferences \1, \2

Match the same text that a previous group captured.

Step-by-step explanation:

  • Step 1: Capture a word with (\w+).
  • Step 2: Use \1 to require the same word again.
  • Step 3: Find repeated words with r"\b(\w+)\s+\1\b".
python 
import re

# Find doubled words
text = "the the cat sat sat on on the mat"
repeats = re.findall(r"\b(\w+)\s+\1\b", text)
print("Doubled words:", repeats)

# Rearrange with backreferences
date = "2026-06-30"
fixed = re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\3.\2.\1", date)
print("\nRearranged:", fixed)

# Match a quoted string (same quote char)
quoted = re.findall(r"(['\"]).*?\1", "'hello' and \"world\"")
print("\nQuoted strings:", quoted)
⚠️ Backreferences only work within the same pattern — they can't match text from a previous call.

🚩 Flags — Change Pattern Behavior

Global modifiers that adjust how regex matches.

📝 7.1 re.IGNORECASE (re.I)

Match regardless of uppercase/lowercase.

Step-by-step explanation:

  • Step 1: Pass re.I as a flag.
  • Step 2: Both "Hello" and "HELLO" match "hello".
python 
import re

text = "Hello HELLO hello HeLLo"

print("No flag:     ", re.findall("hello", text))
print("re.I flag:   ", re.findall("hello", text, re.I))
print("(?i) inline: ", re.findall("(?i)hello", text))
💡 (?i) at the start of a pattern is equivalent to re.I — useful when you can't pass flags (e.g., inside config files).

📝 7.2 re.MULTILINE (re.M)

Make ^ and $ match line starts/ends instead of string boundaries.

Step-by-step explanation:

  • Step 1: Pass re.M.
  • Step 2: ^ matches after each newline.
  • Step 3: $ matches before each newline.
python 
import re

text = "first\nsecond\nthird"

print("No flag:   ", re.findall(r"^\w+", text))
print("re.M flag: ", re.findall(r"^\w+", text, re.M))
print("ends:      ", re.findall(r"\w+$", text, re.M))

📝 7.3 re.DOTALL (re.S) & re.VERBOSE (re.X)

DOTALL makes . match newlines. VERBOSE allows comments in patterns.

Step-by-step explanation:

  • Step 1: re.S lets . cross newlines.
  • Step 2: re.X ignores whitespace and # comments in patterns.
  • Step 3: Combine flags with |.
python 
import re

# DOTALL — match across newlines
html = "<div>\ncontent\n</div>"
print("No DOTALL:", re.findall(r"<div>.*</div>", html))
print("DOTALL:   ", re.findall(r"<div>.*</div>", html, re.S))

# VERBOSE — readable complex patterns
pattern = r"""
    \b          # word boundary
    \w+         # one or more word chars
    @           # at sign
    \w+         # domain
    \.          # literal dot
    \w+         # TLD
    \b          # word boundary
"""
text = "Contact: alice@example.com for info"
print("\nEmails:", re.findall(pattern, text, re.X))
✨ re.VERBOSE is your friend for long patterns — break them into readable, commented lines.

📝 7.4 Compiled Patterns — re.compile()

Compile once, reuse many times — faster and cleaner for repeated matching.

Step-by-step explanation:

  • Step 1: Call re.compile(pattern, flags).
  • Step 2: Call methods on the compiled object directly.
  • Step 3: Reuse across many strings.
python 
import re

# Compile once
email_re = re.compile(r"\b[\w.]+@[\w.]+\.\w+\b")

# Use many times
texts = [
    "alice@example.com sent a message",
    "contact bob@test.org for support",
    "no email here",
]

for t in texts:
    matches = email_re.findall(t)
    print(f"{t!r}: {matches}")

# Access the pattern and flags
print("\nPattern:", email_re.pattern)
print("Flags:  ", email_re.flags)
💡 Python caches recently used patterns automatically, but explicit compile() is clearer and slightly faster for hot loops.

❓ Frequently Asked Questions — Python Regex

Common questions about regular expressions in Python.

What's the difference between match, search, and fullmatch?

+

match() checks only the start of the string. search() scans the entire string for the first match. fullmatch() requires the pattern to match the entire string. Use fullmatch() for validation, search() for finding, match() only when you specifically need start-anchoring.

Why do I need to use raw strings r"..." for patterns?

+

In a regular string, "\d" is just "d" because Python interprets \d as an unknown escape. With r"\d", the backslash is preserved literally. Always use raw strings for regex — it prevents subtle bugs, especially with backslashes.

What's the difference between greedy and non-greedy matching?

+

By default, quantifiers (*, +, {n,m}) are greedy — they match as much as possible. Add a ? to make them lazy: *?, +?, ??, {n,m}?. Lazy matching is crucial when extracting content between delimiters.

How do I match a literal dot . or other special characters?

+

Escape special characters with a backslash: \., \*, \+, \?, \(, \), \[, \], \{, \}, \^, \$, \|, \\. Or use re.escape(string) to escape a whole string automatically.

What is a "catastrophic backtracking" regex?

+

Patterns with nested quantifiers like (a+)+ can cause exponential backtracking on non-matching input, freezing your program. Avoid nested quantifiers on the same character class. Test with long inputs; if it hangs, restructure or use re2/regex modules.

How do I capture multiple groups in findall()?

+

If the pattern has multiple groups, findall() returns a list of tuples, one per match. If there's one group, it returns a list of strings. If there are no groups, it returns a list of full match strings. Use finditer() when you need per-match position or group access.

How do I do case-insensitive matching?

+

Pass re.IGNORECASE (or re.I) as a flag: re.findall("hello", text, re.I). Or prefix the pattern with (?i): re.findall("(?i)hello", text). Both are equivalent.

Why does re.search() return None even though the pattern is there?

+

Common causes: (1) forgot to use a raw string and the backslashes got mangled; (2) pattern anchors ^/$ behave unexpectedly without re.M; (3) uppercase vs. lowercase without re.I; (4) escaped characters like \. vs .. Print your pattern with repr() to verify it's what you expect.

How do I match across multiple lines?

+

Use re.DOTALL (re.S) to make . match newlines, and re.MULTILINE (re.M) to make ^/$ match line boundaries instead of string boundaries. Combine both with re.S | re.M if you need both behaviors.
