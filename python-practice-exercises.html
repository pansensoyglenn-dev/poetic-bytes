🧭 How to Use These Exercises

A repeatable process that turns solving into learning

The recommended workflow

1. Read the task. Understand what the exercise asks before looking at any code.
2. Try it yourself. Give yourself 15 minutes of genuine effort — write your own version in the starter code, run it, see what happens.
3. Only then check the solution. Compare your approach to the provided one. Both may be valid — the point is what you learned in the gap.
4. Re-implement the solution from memory. Close the solution panel, delete your code, and write the whole thing again. This step is where the learning really happens.

💡 If you get stuck on the same exercise for more than 20 minutes, read the solution — that's not cheating, it's efficient. The learning still happens when you re-implement it from memory afterwards. What doesn't work is staring at the same error for an hour without progress.

String Compression (Basic)

Compress runs of repeated characters.

● Hard

Task: Given "aaabbbcc", print "a3b3c2" — each character followed by the count of consecutive repeats.

s = "aaabbbcc"

result = []
prev = s[0]
count = 1

for ch in s[1:]:
    if ch == prev:
        count += 1
    else:
        result.append(f"{prev}{count}")
        prev = ch
        count = 1

result.append(f"{prev}{count}")
print("".join(result))
Expected outputa3b3c2
Show solution
Solution explained
  1. 1The input string.
  2. 3Accumulator for the output chunks.
  3. 4–5prev tracks the current run's character; count counts its length. Start with the first character.
  4. 7Iterate from the second character onward.
  5. 8–9If the character matches prev, increment the count.
  6. 10–12Otherwise, the run has ended — emit prev + count, then start a new run.
  7. 14After the loop, emit the final run — it has no following character to trigger the else-branch.
  8. 15Join the chunks into one string.

Deduplicate Preserving Order

Remove duplicates but keep the original order.

● Medium

Task: Given a list with repeated values, produce a new list where each value appears once — in the order it first appeared.

Expected output[3, 1, 2, 4]
Show solution
Solution explained
  1. 1The input list with duplicates.
  2. 2dict.fromkeys(nums) creates a dict with each element as a key. Since Python 3.7, dicts preserve insertion order — duplicates are dropped but the first occurrence order is kept. list(...) converts the dict's keys back to a list.

Recursive Factorial

Rewrite Exercise 10 using recursion.

● Hard

Task: Define factorial(n) recursively. factorial(0) is 1; factorial(n) is n × factorial(n-1).

def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))
print(factorial(0))
Expected output120 1
Show solution
Solution explained
  1. 1Function definition.
  2. 2–3Base case — for n ≤ 1, factorial is 1. Without this, the recursion would never terminate.
  3. 4Recursive case — calls itself with n - 1.
  4. 6factorial(5) → 5 × factorial(4) → … → 5 × 4 × 3 × 2 × 1 = 120.
  5. 7Base case returns 1 for n=0.

Recursion is elegant for small inputs but can hit Python's recursion limit (~1000 by default) for large n. For anything beyond toy sizes, the iterative version from Exercise 10 or math.factorial is the right choice.

Custom Exception

Define a custom exception class and raise it.

Task: Define ValidationError (a subclass of Exception) and a function validate_age(age) that raises it for negative values.

class ValidationError(Exception):
    pass

def validate_age(age):
    if age < 0:
        raise ValidationError("Age cannot be negative")
    return age

try:
    validate_age(-5)
except ValidationError as e:
    print(f"Caught: {e}")

from dataclasses import dataclass
